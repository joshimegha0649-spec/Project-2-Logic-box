# Pattern Generator and Number Analyzer:

##  Project Overview

The Pattern Generator and Number Analyzer is a Python-based program that allows users to generate star patterns and analyze a range of numbers.

The program provides a menu-driven interface where users can select different options.

##  Features

### 1. Generate a Pattern
- Takes the number of rows as input.
- Generates a right-angled triangle pattern using stars (`*`).
- Displays an error message if the number of rows is not positive.

### 2. Analyze a Range of Numbers
- Takes the starting and ending numbers as input.
- Identifies whether each number is Even or Odd.
- Calculates the sum of all numbers in the given range.
- Displays an error message if the starting number is greater than the ending number.

### 3. Exit the Program
- Allows users to exit the program.
